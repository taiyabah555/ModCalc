
# ModCalc 🧮

**A fast, simple, and free modular arithmetic calculator.**

🚀 [**Try ModCalc Live**](https://taiyabah555.github.io/ModCalc/)

Use the calculator directly in your browser — no installation or coding required!

ModCalc is an open-source web-based calculator designed to help students understand and solve modular arithmetic problems quickly and accurately.

## ✨ Features

- Calculate the modulo of two integers.
- Supports positive and negative numbers.
- Handles very large integers using JavaScript BigInt.
- Displays the quotient and remainder.
- Shows the mathematical equation.
- Provides input validation and helpful error messages.
- Clean, responsive interface.

## 🚀 Getting Started

No installation required!

1. Clone this repository:

   ```bash
   git clone https://github.com/taiyabah555/ModCalc.git
   ```

2. Open the project folder.
3. Open `index.html` in your web browser.
4. Enter your dividend and modulus.
5. Click **Calculate**.

## 🎯 Project Goals

ModCalc aims to make modular arithmetic easier and more accessible for students through a simple interface and clear mathematical explanations.

Planned improvements include:

- Modular addition, subtraction, and multiplication.
- Modular exponentiation.
- Modular inverse.
- Greatest Common Divisor (GCD).
- Extended Euclidean Algorithm.
- Chinese Remainder Theorem.
- Step-by-step mathematical solutions.
- Dark and light themes.
